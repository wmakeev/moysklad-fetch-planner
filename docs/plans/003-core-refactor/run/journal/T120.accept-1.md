1. Error path: `samples/wait-for-request-slot-1.ts:100–105` сохраняет `push(err)` и один `next()` для Error. Установленный `@types/highland/index.d.ts:650–658` объявляет аргумент `err: Error`, поэтому прежний truthiness-check избыточен для объявленного типа. `instanceof Error` сохраняет саму развилку, необходимую для runtime-пути без ошибки; безусловный `push(err)` из ложной типовой предпосылки не введён. Проверка ограничена согласованным контрактом Error, произвольные truthy non-Error значения и Error из другого realm не заявлены как поддерживаемый вход этого sample.

При отсутствии ошибки `null`/`undefined` не проходят `instanceof Error`, и управление по-прежнему доходит до end-of-stream либо data.
