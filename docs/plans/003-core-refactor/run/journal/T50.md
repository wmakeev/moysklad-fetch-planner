## Связь утверждений с критериями

D06 red выполнен до production-правки. Неизменённое утверждение `assert.equal(correction, expected, 'Correction is clamped at the state transition')` дало actual=1, expected=-1 при max2 и actual=3, expected=-3 при max4; max1 ожидаемо был зелёным и до исправления (нулевая correction).
