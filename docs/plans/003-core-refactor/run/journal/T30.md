## Решение [ROOT, ALT, CONSIST, SURFACE]

Выбран единый terminal transition settleAction и явное состояние queued/running/terminal. Альтернатива — добавлять независимые catch/finally к transport и каждому emit — оставляет несколько владельцев reject/requeue и не запрещает повтор terminal action. В выбранном варианте observer вызывается до resolve/requeue; ошибке принадлежит единственный fail, вторичному observer exception — только фиксированное process.emitWarning('FetchPlanner observer failed'), исключение самого diagnostic path перехватывается. Оригинальный Error сохраняет identity. Transport вызывается без нового this binding.

Освобождением inflight владеет finally ровно одного attempt. Request throw отвергает action сразу, но await отправленного transport остаётся активным: поздний response очищается, поздний reject наблюдается, повторного fetch-error/settlement нет. Явная ошибка при извлечении action не в queued предотвращает тихий повтор terminal action [FRAGILE]. Новых публичных options/events/injection нет.

Минимальное необходимое сопряжение с T60: локальная переменная response хранит planner-owned ответ до передачи потребителю; единый discardResponse вызывается из finally, не await и с перехватом sync/rejected cancel. Сюда попадают non429 header/observer failure и поздний ответ terminal action; переданный Response тот же и body нетронут. Это путь передачи владения, а не заявление о завершении T60: полная матрица429/cleanup failure/hanging cancel/loopback остаётся T60.

Первый общий check выявил сохранённое требование старого getter: сразу после await fetch inflight ещё 1, после чтения body — 0. Вместо изменения теста вне границ сохранён прежний порядок consumer job и release через один await Promise.resolve() в finally [CONSIST]. Это не ожидание body/cleanup и не изменение transport-owned cancellation.

```js
import assert from 'node:assert/strict'
import { setTimeout as delay } from 'node:timers/promises'
import { Response } from 'undici'
import { FetchPlanner } from '../../src/index.js'

const scenario = process.argv[2]
const original = new Error('original failure')
const secondary = new Error('secondary failure')
const planner = new FetchPlanner(
  () => {
    if (scenario === 'sync-transport') throw original
    if (scenario === 'error-observer') return Promise.reject(original)
    return delay(10).then(() => new Response(null))
  },
  {
    jitter: 0,
    eventHandler: {
      /** @param {string} name */
      emit(name) {
        if (scenario === 'request-observer' && name === 'request') throw original
        if (scenario === 'error-observer' && name === 'fetch-error') throw secondary
      }
    }
  }
)
await assert.rejects(planner.getFetch()('http://offline.test/'), error => error === original)
await delay(30)
assert.equal(planner.getActionsQueueLength(), 0)
assert.equal(planner.getCurInflightRequestsCount(), 0)
console.log('settled once; queue and inflight empty')
```
