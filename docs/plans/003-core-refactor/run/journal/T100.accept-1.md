## Поведение и краевые пути

- native loopback suite проверяет URL, Request POST, init override PUT с заменой тела, string/Buffer/FormData c File/File/ReadableStream, идентичность Response и неиспользованное тело до передачи потребителю. HTTP404/503 остаются responseType OK.
- undici/fake suite проверяет Request metadata и init override, неизменные input/init/body/signal/Response, строковый и Buffer retry с теми же объектами и ровно двумя attempts.
- String URL без init сохраняет method undefined; Request без init берёт POST; явно переданный init.method имеет приоритет. request и response metadata проверяются конкретными значениями, fetch-error metadata POST также проверяется на one-shot/transport ошибках.
- Шесть native one-shot путей штатного strict child: Request/stream после429, предварительно disturbed Request/stream, предварительно locked Request/stream. Результат — исходная transport error, attempts 2 для retry и 1 для предварительно непригодного тела, один fetch-error и один settlement, queue/inflight 0, следующий action проходит.
- Независимая проба повторяет шесть one-shot путей настоящими native и undici transport через loopback; дополнительно проверены Request GET с пустым init, POST с init.method undefined и заменой headers без потери тела, lowercase post metadata, URL/string с пустым init, реальные payloads, HTTP400/500 OK и идентичный Response, pre-aborted signal с исходным reason.
- Независимая queued-abort проба: при занятом единственном slot abort не удаляет queued action; после освобождения transport получает тот же уже aborted signal и может успешно завершить запрос, если игнорирует signal. Это characterization transport ownership, без обещания planner cancellation и без закрытия D09.
