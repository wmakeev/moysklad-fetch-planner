## Проверяемое поведение и происхождение

- HTTP429/200/500 × invalid header/response observer throw/late terminal response: suite проверяет underlying ReadableStream cancel1, затем снова cancel1 после продвижения времени; один settlement и fetch-error, следующий action завершается, queue/inflight0. При late request observer action уже rejected, inflight остаётся1 до settlement транспорта, затем очищается body без повторного завершения. Адреса: test/body-cleanup.test.ts:11, src/index.ts:730–784.
- Retry discarded429: finite/rejected/hanging/synchronous/null cancel. Доставка исходного Response потребителю сохраняет identity/bodyUsed=false/cancel0; inflight заканчивается на headers, следующий action не ждёт hanging cancel. Адрес: test/body-cleanup.test.ts:105. Rejected/sync cleanup не создают unhandled в strict режиме.
- Дополнительно собственная матрица расширяет rejected/hanging/sync/null cancel на каждый из девяти error/late путей (36 тестов), отдельно проверяет legacy parallel429005 retry с rejected cancel (ещё один). В каждом error path: cancel1 либо0 при null, один reject/fetch-error, два transport starts, неизменённый HTTP500 Response следующего action с читаемым body и cancel0. Полный код сохранён ниже.
- Переданные HTTP200/500 Response остаются теми же объектами с нетронутым body; потребитель читает ожидаемый текст. Адрес: test/body-cleanup.test.ts:157. Новая политика body concurrency не введена.
- Strict loopback child использует реальные status/headers/body и один undici connection; семь незавершённых discarded bodies должны освободить соединение для следующих запросов. Assertions требуют 7 вызовов cancel, 7 конечных settlements, 7 server close и 15 запросов. finally закрывает agent, connections и server. Адрес: test/helpers/child.mjs:43–176. Natural exit подтверждён strict suite и обоими полными прогонами; watchdog означает fail, не успешное завершение (test/body-cleanup.test.ts:187–205).
- Прежние strict lifecycle children error-observer/sync-transport/request-observer проверены после изменения общего helper: прошли. В child нет process.exit, unref или доступа к private timer. Hanging cancel находится только в fake probes, его завершение не обещается.
