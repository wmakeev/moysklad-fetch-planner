## Выбор и границы [ROOT, ALT, CONSIST, SURFACE]

Реализован выбранный T80 generic-вариант: F проходит constructor/getFetch/wrapFetch/options/events/instance; Scheduled распределяется по union и возвращает новую нормализованную функцию, не обещая свойства исходного callable. Альтернатива overloads отклонена по принятому T80: теряет custom Response/protected subclass и не закрывает чужой Node EventEmitter при перегруженном emit. emit — единственная function-property с mapped tuple union из EventMap. Default класса — undici, default событий — union. Новых корневых экспортов, options, runtime adapters или runtime dependencies нет.

src/fetch-types.ts — разрешённый внутренний type-only helper; его импорты стираются из runtime. Два узких внутренних assertions в planner связывают извлечённые Parameters/ReturnType с generic callable и bound Scheduled; они не расширяют публичные входы и не возвращают F. Все consumer fixtures без any/cast/ts-ignore/skipLibCheck. Ниже есть точная проверка одинакового emitted JS старого и нового production-кода при removeComments.

@types/node закреплён на 24.19.2 по первичным declarations и эксперименту T80; direct undici-types 7.3.0 и dev-only undici 7.3.0 сохранены. Изменения lock относятся к Node types, их undici-types 7.24.6 и peer-идентификаторам зависимых dev-инструментов. Замены runtime undici-types 7.3.0 нет.
