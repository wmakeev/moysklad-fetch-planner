## Контроль нарушений

`verify.py probes` создаёт личную внешнюю копию source/test/samples/scripts и конфигов; в фазе probes node_modules symlink ведёт только на установленный root-граф. Затем finish.py удаляет именно этот symlink и выполняет fresh frozen install для проверки независимой установки. Линтер не выполняет probe-код и не делает process.exit runtime вызовов.

Для каждой строки ниже создан отдельный `src/t50-probe.ts`, затем отдельный `test/t50-probe.ts`. Каждая команда: `pnpm exec oxlint --type-aware --report-unused-disable-directives src test samples scripts --format json`. Exit 1 и нужная error severity проверены assertions по filename/code; исходные два warnings допускаются отдельно. Сводка probe-summary.json и отдельные src-*.log/test-*.log содержат полные diagnostics.

| Вставка | Обязательный code | Src/test exits |
| --- | --- | --- |
| `Promise.resolve(1)` | typescript(no-floating-promises) | 1 / 1 |
| `[1].forEach(async value => { await Promise.resolve(value) })` | typescript(no-misused-promises) | 1 / 1 |
| `await 42` | typescript(await-thenable) | 1 / 1 |
| `JSON.parse("null")()` | typescript(no-unsafe-call) | 1 / 1 |
| `export const unsafe = JSON.parse("null")` | typescript(no-unsafe-assignment) | 1 / 1 |
| `JSON.parse("null").field` | typescript(no-unsafe-member-access) | 1 / 1 |
| `console.log(...JSON.parse("null"))` | typescript(no-unsafe-argument) | 1 / 1 |
| `export function unsafe(): string { return JSON.parse("null") }` | typescript(no-unsafe-return) | 1 / 1 |
| `process.exit(1)` | eslint(no-restricted-properties) | 1 / 1 |

После удаления src-проб, test-проб и всех дополнительных проб: src-restored.log, test-restored.log, copy-final-restored.log — exit 0, 10 files, 2 исходных warnings. Source/test/scripts реально анализируются: lint-inputs.log перечисляет исходные 10 файлов, в том числе scripts/check-coverage.mjs. Отдельные scripts/t50-probe.mjs и samples/t50-probe.ts с необработанным Promise дают no-floating-promises exit 1; scripts-floating.log, samples-floating.log. В пробах нет новых explicit any/void или skipLibCheck.

Старый точечный uint8array-extras.stringToUint8Array specifier сохранён без установки новой зависимости.

`process['exit'](1)` и `const { exit } = process; exit(1)` дают no-restricted-properties exit 1 (exit-computed.log, exit-destructure.log). `const alias = process; alias.exit(1)` даёт exit 0 без этого code (exit-alias-limits.log). ## Воспроизведение и промежуточные ошибки harness

Основные проверочные scripts: verify.py (probes/regression/immutable), finish.py (why/list/fresh install), fix-probe.py. Внешние копии и логи сохранены для приёмки, shared T10/T15 прототипы не удалялись. Для повторных probes требуется новое имя C вместо уже существующей копии: защита `assert not C.exists()` предотвращает перезапись. Команды gates можно повторять прямо из корня с pinned PATH; все команды из таблицы реально выполнялись.

Первый regression harness ожидал TAP `# tests 13`, но pinned Node при pipe напечатал `ℹ tests 13`; команда test была успешной, assertions скорректированы к фактическому reporter, затем test/coverage проверены. Первый pnpm why с `--depth Infinity` получил exit 2: pnpm12 принимает числовую глубину. По штатной help исправлено на 1000, why/list прошли; их провал не выдавался за пустой граф. Первое сравнение package keys ошибочно взяло YAML-документ package manager; итог повторён на последнем packages разделе и записан в lock-package-delta.json. Эти исправления касаются только временного verifier.
