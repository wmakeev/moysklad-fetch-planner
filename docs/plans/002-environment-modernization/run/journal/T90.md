## Решения

Пять обязательных jobs без `continue-on-error`: check с coverage на `.node-version`, unit на 26.x с dev install, package/type gate на `.node-version`, единственная сборка runtime artifact на `.node-version`, runtime matrix 24.0.0/24.x/26.x. В runtime jobs нет checkout, pnpm или установки root dev-графа; только download и установка tarball через npm с `--ignore-scripts --omit=dev`. Отсутствие consumer undici проверяется отдельно. Временный consumer удаляется EXIT trap. Smoke проверяет root/deep imports, GET/POST через локальный transport, исходный Response; HTTP API/сеть во время assertions не используются.

Переиспользован `test/package/fixtures/runtime.mjs`, замены import выполняются при подготовке artifact. Альтернатива — новый runtime script/alias: она создала бы второй smoke и потребовала новых lint/knip входов без нового поведения [ALT, CONSIST, SURFACE]. Tarball собирается один раз в artifact job; package gate отдельно выполняет lifecycle/type проверки T80. Upload/download передают tarball, fixture и SHA256SUMS; каждый runtime сначала проверяет оба файла. Runtime matrix имеет `fail-fast: false` для отдельных результатов каждой строки.

Codecov upload удалён как необязательная внешняя интеграция; обязательный `pnpm coverage` сохранён. Workflow не использует секреты, MOYSKLAD_TOKEN, dotenv, `.env`, live или publish. События: PR и push master. Права только `contents: read`, checkout с `persist-credentials: false`. Установка: checkout → Node → pnpm по packageManager (version input отсутствует) → явный frozen install. Cache отключён, поэтому нет зависимости setup-node от ещё не установленного pnpm.
