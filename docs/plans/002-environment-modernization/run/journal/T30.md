## Принятые решения

Общий tsconfig стал явным strict NodeNext с noEmit; production включает только src и пишет build/src, test config включает src/test и пишет __temp/test-build. Сохранены ES2022, ES2023 lib, checkJs=true, exactOptionalPropertyTypes=false и все прежние strict options. skipLibCheck=false усиливает прежнюю проверку деклараций. Типы Node заданы явно. sourceMap/declaration включены в обеих emit-конфигурациях.

При первой проверке с skipLibCheck=false TypeScript 5.7.3 выявил TS2732: декларации Piscina импортируют ../package.json. Добавлен resolveJsonModule=true: импорт разрешается без ослабления проверки библиотек и без изменения зависимостей. После этого общий typecheck прошёл. Ошибка и исправление относятся к конфигурации компилятора; код Piscina и проекта не менялся [ROOT, VERIFY].

build вызывает только production compile; compile:dev/build:dev направлены на test build без lint/fix/test. Сохранён существующий способ очистки через rm с двумя фиксированными именами. Альтернатива — отдельный scripts/clean.mjs с выбором каталога; дополнительный файл и интерфейс не нужны для этой задачи [ALT, SURFACE]. Новых зависимостей нет, pnpm-lock.yaml не менялся. Удаление неиспользуемых @tsconfig dependencies оставлено дальнейшему анализу зависимостей, без расширения T30.
