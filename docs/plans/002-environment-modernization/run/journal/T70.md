# T70 — Knip и немутирующий check

Статус: done. Выполнено 2026-10-30, только T70; исходники, scheduler, публичный API и чужая errorLimits не изменялись. Субагенты, секреты, live/API, git mutations и следующие задачи не использовались.

## Реализация и решения

- `knip.json`: явные входы `src/index.ts`, unit/live, URL worker, четыре исполняемых sample и `scripts/check-coverage.mjs`; `project` охватывает все TS из src/test/samples и JS/MJS/CJS/TS из scripts, включая потенциально недостижимые файлы. Generated build не нужен для анализа.
- Публичные экспорты входов сохраняются через явное `includeEntryExports: false`; `FetchPlanner`, `wrapFetch`, event types и исходные declarations не удалялись. Альтернатива с проверкой экспортов библиотечного входа давала бы ложные срабатывания на внешний API [ALT, VERIFY]. Подсказки о четырёх повторно обнаруженных входах оставлены видимыми: явный список требуется брифом [EXPLICIT]. Категории diagnostics не отключались.
- Удалены только `@tsconfig/node22` и `@tsconfig/strictest`: Knip сообщил unused devDependencies, а действующие tsconfig содержат собственные compilerOptions и не расширяют эти пакеты. Lock изменён только для этих двух пакетов.
- Точные исключения: `dotenv` для существующего ручного `node -r dotenv/config` в комментарии `samples/demo.ts`; бинарник `report` для ложного срабатывания встроенного c8 parser на `c8 report`. Причины и условия снятия записаны в README. Альтернатива удаления dotenv ломала бы описанный ручной способ запуска sample [ALT]. Runtime check dotenv не загружает.
- `package.json`: `knip`, последовательный `check = typecheck && lint && format:check && knip && test`; knip.json добавлен в обе существующие команды форматирования. Нет fix, consumer installs, live или dotenv в check.

Поэтому окончательная Knip-проба повторена в независимой fresh-install копии через прямой pinned Node CLI, с запретом сети, без installs и без общей node_modules. Пробные файлы и manifest-правки удалены; общий allowlist root повторно проверен и совпал. Для будущих отрицательных manifest-проб учитывать автоматический install перед pnpm script [VERIFY].

- [Knip: Configuration](https://knip.dev/reference/configuration): entry/project, includeEntryExports и точные ignoreDependencies/ignoreBinaries.
