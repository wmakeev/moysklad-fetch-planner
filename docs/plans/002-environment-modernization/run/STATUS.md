# Состояние плана 002

## Статус

Минимум Node 24 установлен в обоих manifests; compiler, 13 offline tests и lint baseline независимо проверены. Перед дальнейшей миграцией осталось выбрать объём статических Node-проверок.

## Ждёт тебя

Рекомендую один oxlint с точным запретом process.exit и обязательными проверками опубликованного пакета. Это проще второго линтера; однако часть прежних статических Node/dependency проверок теряется и package tests не являются полным эквивалентом. Требуется разрешить эту ограниченную потерю. Альтернатива — сохранить ESLint Node guard на собранном JS; отдельный TS5 parser не нужен.

## Решено на риск

Повышение минимального Node принято владельцем; будущий выпуск major. Проверяющий той же моделью в свежем контексте. Код T15 независимо проверен; исправление устаревшего абзаца evidence сверено только оркестратором по правилу T3 малых исправлений.
