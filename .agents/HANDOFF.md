# Передача

План003 завершён локально; следующий шаг — подготовить отдельный план этапа4 — [карта завершённого прогона](../docs/plans/003-core-refactor/run/README.md), [сквозная приёмка](../docs/plans/003-core-refactor/run/journal/plan.md).

До будущего major-выпуска нужны отдельные решения по D09 queued cancellation/stop, D10 one-shot replay, D12 незавершённой errorLimits, коду1073 без legacy и429 без временных hints, а также настоящий зелёный Actions-run. Локальная пакетная матрица и smoke на Node не заменяют Actions. Защитный эффект errorLimits в003 не реализован; форма/defaults сохранены как исходная работа владельца. Этап4 не начат.

Архитектура и фактические гарантии — README и docs/architecture.md. Почему нужны mapped tuple-union emit и раздельные native/undici Response types — в принятом [контракте Fetch](../docs/plans/003-core-refactor/evidence/fetch-contract.md); generic overload-shaped handler пропускал несовместимый EventEmitter, поэтому возвращать старые перегрузки ради аннотаций нельзя.

Для следующих планов: копировать и хешировать только явный список разрешённых входов; секретные .env/.env.* включая example исключать до чтения. Runtime проверять по фактическому пути, не только по наличию версии в менеджере. Документационные гарантии проверять и в публичном JSDoc: он попадает в tarball, узкий файловый scope не отменяет сквозную цель. Приёмка использовала свежие контексты одной GPT-модели из-за недоступности Claude, поэтому независимость ограничена. Подробные причины, доказательства и история возвратов сохранены в папке прогона.
